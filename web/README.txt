VTuberForge Frontend

How to run:
1. Start your Go backend.
2. If your backend uses /api routes, keep config.js as-is.
3. If it does not use /api, the app falls back automatically.
4. Open index.html in the browser.

What is included:
- public home
- login/register
- JWT storage
- refresh token support
- private lessons page
- lesson completion via API
- profile with completed lessons
- featured news layout
- admin panel with create/delete for lessons and news
- admin page hidden from non-admin users
- improved futuristic design
